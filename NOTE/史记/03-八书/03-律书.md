| 类别 | 律名         | 约配月/节气    |
| ---- | ------------ | -------------- |
| 阳律 | 黄钟         | 十一月（冬至） |
| 阳律 | 太蔟（太簇） | 正月           |
| 阳律 | 姑洗         | 三月           |
| 阳律 | 蕤宾         | 五月           |
| 阳律 | 夷则         | 七月           |
| 阳律 | 无射         | 九月           |
| 阴吕 | 大吕         | 十二月         |
| 阴吕 | 夹钟         | 二月           |
| 阴吕 | 中吕（仲吕） | 四月           |
| 阴吕 | 林钟         | 六月           |
| 阴吕 | 南吕         | 八月           |
| 阴吕 | 应钟         | 十月           |
