## 六国年表
魏、韩、赵、楚、燕、齐

## ① 三家分晋—田氏代齐过渡期（前475—前386）

### 周室

**姬氏午（周威烈王／命三晋为诸侯）**
→ 命韩赵魏／列为诸侯／礼崩乐坏／天子盖章
→ 论：太史公于《六国年表序》明言"非三晋之坏礼，乃天子自坏之"——周王亲手认证篡位者，旧秩序从此名存实亡
→ 附：前403命三晋事详《周本纪》《晋世家》，年表仅记"命魏韩赵为诸侯"

**姬氏仁（周元王／年表起点）**
→ 即位承敬王／春秋终战国始／孔子卒年
→ 论：元王元年司马迁定为战国起点，但当年无事可记——断代之虚在此
→ 附：孔子前479死、左氏传绝笔（他书单标）

### 晋→三晋

**姬氏骄（晋幽公／晋名存实亡）**
→ 仅余绛曲沃／反朝三晋／君如大夫
→ 论：幽公时晋侯已反朝韩赵魏——主仆倒置，春秋分封制最后一丝体面彻底撕碎
→ 附：幽公淫妇人、被盗杀（他书单标）

**姬氏斯（魏文侯／李悝变法首霸）**
→ 任李悝变法／用吴起守西河／尊卜子夏／三晋最强
→ 论：文侯是战国第一个"变法图强"的模板——尊儒变法两不误，魏国霸业全靠他三十年打底
→ 附：李悝《法经》、子夏西河设教、西门豹治邺（他书单标）

**姬氏击（魏武侯／文侯子）**
→ 继位守成／败楚取陕／不续霸而骄
→ 论：武侯有父之余烈而无父之识——吴起走楚，魏国人才外流从此始
→ 附：吴起奔楚、武侯浮西河而叹（他书单标）

**姬氏都（赵烈侯／赵始侯）**
→ 命为诸侯／用公仲连／任牛畜荀欣
→ 论：烈侯以歌者进谏为美谈，赵国政治风气在战国初期最宽松
→ 附：番吾君荐荀欣、徐越（他书单标）

**姬氏虔（韩景侯／韩始侯）**
→ 命为诸侯／灭郑前奏／地狭兵弱
→ 论：韩在三晋中最弱，景侯起家靠赵魏提携，地缘决定韩国永远只能当配角
→ 附：韩景侯伐郑取雍丘（他书单标）

### 齐

**姜氏贷（齐康公／姜齐末君）**
→ 田和迁康公／食一城奉姜祀／姜齐绝祀
→ 论：康公是被架空的活死人——姜氏享齐六百余年，亡于大夫之手而非外敌
→ 附：康公放逐于海上、食一城（他书单标）

**妫氏和（田太公／田氏代齐）**
→ 迁康公于海上／自立为齐侯／前386列诸侯
→ 论：田氏代齐是春秋以来"以下犯上"最彻底的一次——从陈完奔齐到田和篡位，历九世二百余年
→ 附：田常杀简公、田盘、田白、田和逐君（他书单标）

### 秦

**嬴氏师隰（秦献公／止乱复振）**
→ 止内乱即位／废人殉／徙治栎阳／石门之战
→ 论：献公结束秦十年四君的内乱循环，为孝公商鞅变法铺路——他是秦走向强权的"清道夫"
→ 附：献公兵围降魏、少梁之战（他书单标）

**嬴氏昌（秦出子／被弑）**
→ 两岁即位／母党专权／被庶长改迎献公
→ 论：出子之死是秦国内乱的最后一幕——庶长菌改杀出子母，迎献公，秦从此不再让幼主即位
→ 附：出子被沉诸渊（他书单标）

### 楚

**芈氏疑（楚悼王／吴起变法）**
→ 用吴起变法／损有余补不足／南平百越
→ 论：悼王是楚国唯一一次真正变法的窗口——可惜他一死吴起就被射杀，楚之不变法终致灭亡
→ 附：吴起相楚、损楚旧贵族、悼王死吴起走（他书单标）

**芈氏当（楚声王／被盗杀）**
→ 在位仅六年／被盗所杀
→ 论：声王之死是楚国中衰期的缩影——中央权威崩到连盗贼都敢杀王
→ 附：声王被盗杀、楚益弱（他书单标）

### 燕

**姬氏平（燕孝公）**
→ 继位守成／从山戎退／燕复小弱
→ 论：燕在战国初期几乎无存在感——地缘偏远，既无变法也无争霸，纯属年表凑数
→ 附：燕桓公、燕文公（他书单标）

## ② 魏国独霸—齐秦崛起期（前385—前341）

### 总体特点

- **魏国是战国第一个"霸主模板"**：文侯底子+武侯守成+惠王前期膨胀，魏独霸中原近六十年，但桂陵、马陵两战被打回原形——霸主死于"四面树敌还不自知"。
- **商鞅入秦是这段最狠的蝴蝶效应**：前356孝公任商鞅变法，秦从"夷狄之邦"变成"战争机器"，为后来六国一个一个吃掉埋下种子。
- **齐威王是东方最大变量**：继位前九年沉湎酒色，一醒过来整饬吏治、任用邹忌、孙膑，桂陵马陵两战把魏国打废——齐国从此取代魏国成为东方霸主。
- **楚国在宣王时期闷声发大财**：吴起死后楚国变法中断，但宣王守住地盘、不掺合中原混战，等魏齐两败俱伤再出来捡便宜。
- **周室彻底沦为"纪年工具"**：安王、烈王、显王，除了给诸侯"命为诸侯"盖个章，啥也干不了。

**姬氏骄（周安王／命齐田和、命三晋）**
→ 命田和为齐侯／命三晋为诸侯／天子盖章机
→ 论：安王在位二十六年，干了两件事——给田氏盖章、给三晋盖章，周室从"共主"彻底降级为"认证机构"
→ 附：安王崩、烈王立（他书单标）

**姬氏扁（周显王／诸侯称王）**
→ 致胙秦孝公／诸侯自称为王／周室虚名
→ 论：显王时秦孝公称霸、齐魏称王，周室连盖章都没人请了——致胙是秦给周最后一点面子，周回赠"胙肉"纯属政治cosplay
→ 附：前344逢泽之会、秦孝公称伯（他书单标）

→ 附：武侯浮西河而叹、吴起走楚（他书单标）

**姬氏䓨（魏惠王／桂陵马陵败方）**

→ 附：惠王问孟子"何以利吾国"、庞涓、孙膑膑脚（他书单标）

### 齐

**妫氏婴齐（齐威王／桂陵马陵胜魏）**

→ 论：威王前九年装死，一醒就砍了两个贪官、赏了两个清官——齐国之强不在地广而在吏治清明

→ 附：桓公午卒、威王立（他书单标）

### 秦

**嬴氏渠梁（秦孝公／商鞅变法）**

## ③ 合纵连横高峰（前340—前284）

### 总体特点

- **纵横家是这段的主角**：张仪连横、苏秦合纵，嘴皮子决定战争与和平——这是春秋没有的新物种，专业外交家+间谍+策士三位一体。
- **秦惠文王是第一个把"连横"玩成国家战略的秦王**：东出函谷、欺楚、伐魏、取河西，把商鞅留下的战争机器开到中原门口。
- **楚怀王是这段最惨的冤大头**：被张仪骗了两次、被秦扣了一辈子、客死咸阳——楚国从此一蹶不振，屈原投江就在这段。
- **赵武灵王胡服骑射是军事革命**：从"车战+步兵"转向"骑兵突击"，赵国一夜之间从弱国变成军事强国，为后来长平之前赵国撑住局面打下底子。
- **齐湣王灭宋是"贪婪毁霸"的教科书**：宋国是中原膏腴之地，齐灭宋后六国震恐，乐毅率五国联军伐齐——齐几乎亡国，从此退出争霸。
- **燕昭王复仇是这段最燃的暗线**：父王哙让国乱死，自己从赵国回来即位，筑黄金台招贤，等了二十八年终于乐毅伐齐报仇——隐忍和耐心比刀剑更狠。

### 秦

**嬴氏驷（秦惠文王／连横破合纵）**

→ 附：张仪、司马错取巴蜀、魏章、樗里疾（他书单标）

**嬴氏荡（秦武王／举鼎死）**

→ 论：武王是秦国有史以来最莽的君——为了"举鼎示威"把自己举死，但他在位四年打通了通往周室的路

**嬴氏则（秦昭襄王／长平前传）**
→ 继位少年／宣太后摄政／魏冉专权／取穰
→ 论：昭襄王在位五十六年，前期全是宣太后和魏冉的戏——但他熬死了所有对手，最后自己亲政开启灭国模式
→ 附：宣太后、魏冉、芈八子（他书单标）

## ④ 秦昭襄王独霸—秦并六国（前283—前221）

### 总体特点

- **秦昭襄王在位五十六年，把"远交近攻"玩成灭国流水线**：范雎献策后秦不再四面出击，而是"先打最近的韩魏、稳住齐楚燕"，一个一个捏。长平一战坑杀赵军四十五万，赵国从此废了。
- **完璧归赵、渑池之会是秦赵外交博弈的巅峰**：蔺相如靠"人头+血溅"逼秦昭王让步——但外交胜利掩盖不了国力差距，十年后长平秦还是把赵国按在地上打。
- **邯郸之围是秦统一前最大的挫折**：前258—前257秦军围赵都邯郸三年，信陵君窃符救赵、楚春申君来援，秦军大败——但秦只是退了一步，并没有伤筋动骨。
- **吕不韦是"仲父政治"的极致**：庄襄王死、始皇年幼，吕不韦独揽大权，编《吕氏春秋》、养三千门客、甚至跟太后有私——最后被嬴政逼死，权力彻底收归秦王。
- **最后十年灭六国是"收割"而非"征服"**：前230—前221十年间六国一个接一个倒，不是秦突然变强了，是前面一百年已经把六国的血放干了。
