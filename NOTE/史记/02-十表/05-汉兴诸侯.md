《汉兴以来诸侯王年表》这张表，太史公把汉高祖称帝（前202年）到汉武帝时期的所有诸侯王全排进去了。数量比你想象的多——**不是一个两个，是一窝一窝地封。**

## 一、高祖时期：一口气封了16国

### 异姓王7国（先封后灭）

| 国   | 王                | 结局                                   |
| ---- | ----------------- | -------------------------------------- |
| 楚   | 韩信→贬淮阴侯→杀  | 前201年夺齐王改楚王，前196年杀         |
| 梁   | 彭越              | 前196年剁肉酱                          |
| 淮南 | 英布              | 前196年反，被杀                        |
| 赵   | 张耳→张敖（女婿） | 张敖被废为侯                           |
| 燕   | 臧荼→卢绾         | 臧荼反，卢绾后来叛逃匈奴               |
| 长沙 | 吴芮              | **唯一善终的异姓王**，传到五代无后国除 |
| 韩   | 韩王信            | 投降匈奴，死在胡地                     |
